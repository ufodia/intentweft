# Security reporting

Do not put credentials, private project contents, or exploit details affecting a live system in a public issue. Use this repository's GitHub Security tab to report privately if private reporting is available. Otherwise open a minimal issue requesting a private contact channel without sensitive details.

Bundled scripts use the Python standard library, perform no network calls, and do not execute project commands from reports. The snapshot helper reads explicitly selected files. Review reports still contain project metadata, source paths, and possibly sensitive prose supplied by the author; keep them private when appropriate.

Review any skill and script before installing it. Agent permissions remain controlled by the host. The skill cannot grant itself additional access or turn an untrusted document into authorization.
